# VCPE-rna 接入 rna_robot 平台分析（P3 前置，本轮只分析不改代码）

- 日期：2026-09-01
- 范围：ASO/siRNA 视图的响应预测路径（MODZ / AIDO.RNA-Pert）→ VCPE-rna 引擎
- 结论先行：**推荐"离线导出缓存"模式**——VCPE-rna 批量推理一次、按 AIDO 缓存同构 schema 导出，
  平台侧只换缓存文件 + 归属文案，**零新依赖**（平台连 torch 都不用装）。

## 一、现状链路（谁产生什么、谁消费什么）

```
ASO 序列 → aso_offtarget_transcriptome.py（比对 gene_transcripts.fa 找脱靶）
        → top 脱靶基因
        → immune_simulation/engine/virtual_cell.py 的 tier 路由：
            Tier-1  实测基因 → LINCS L1000 MODZ（kd 缩放近似，HepG2）      [不变]
            Tier-2  未实测   → AIDO.RNA-Pert 预计算缓存                     [替换点]
        → 前端 immune_sim.js（MODZ 棒图 / ASO 校准 top 基因替换——框架已存在）
```

关键落点：
| 文件 | 作用 | 行号 |
|---|---|---|
| `immune_simulation/outputs/aido_vc_cache.json.gz` | Tier-2 预计算缓存：**55,336 基因 → {top_up, top_down} 方向列表** | 缓存本体 |
| `immune_simulation/engine/virtual_cell.py` | Tier 路由 + AIDO 缓存加载（L74-92）+ Tier-2 预测（L421）+ MODZ（L551）+ caveat（L924-989，`is_aido` 标志） | 引擎 |
| `rna_robot/utils/aso_offtarget_transcriptome.py` | 脱靶搜索 + "Powered by GenBio AI" 文案（L264） | 接口 |
| `rna_robot/static/immune_sim.js` | MODZ 显示 + ASO top 基因替换逻辑（L229/362-363，**替换框架已存在**） | 前端 |
| `immune_simulation/build_lincs_hep_cache.py` | Tier-1 LINCS 缓存构建 | 不动 |

## 二、接入会改变的数据（按类）

| # | 类别 | 变化 | 说明 |
|---|---|---|---|
| 1 | **模型工件** | `aido_vc_cache.json.gz` → `vcpe_cache.json.gz`（1 换 1） | 生成器从 `AIDO/vertical_slice/export_predictions.py` 换成 VCPE 推理导出脚本；权重 = `ckpt_best_cosine.pt`（871M）+ `rna_encoder_aligned.pt`（2.5M） |
| 2 | 缓存 schema | **保持同构**：per-gene `{top_up, top_down}` 方向列表 | VCPE 从 HVG-2000 预测排序导出，下游消费方式不变 |
| 3 | **Tier-2 覆盖面** ⚠️ | 55,336 → ~19,790（ESM2 表上限，+HGNC `+1` 别名） | **诚实提示**：可作敲低靶标的基因集合缩小；缓解项：响应输出（2000 HVG）不受限，且 `lookup_seq` 的 Ensembl/`+1` 回退已就位 |
| 4 | **归属文案** ×3 | "Powered by GenBio AI" → VCPE 措辞 | `virtual_cell.py:436/932`、`aso_offtarget_transcriptome.py:264`——**这是接入的核心动机，文案不改等于白换**；`is_aido` 标志同步改 `is_vcpe` |
| 5 | 细胞类型标注 | cache `cell_type` 字段 | AIDO=单细胞型（K562 训练）；VCPE=三数据集联合（K562×2 + RPE1），标注与 caveat 更新 |
| 6 | 前端 | caveat 文案 + MODZ→top response gene 替换的措辞 | 替换框架已有（immune_sim.js:362），改动小 |

**不变**：Tier 路由逻辑、Tier-1 LINCS 实测真值、off-target 搜索、8000 服务接口、前端替换框架。

## 三、质量 trade-off（诚实标注）

| 维度 | AIDO.RNA-Pert（现役） | VCPE-rna（接入后） |
|---|---|---|
| fm_cosine（嵌入空间） | 0.984 | 0.9710（**-1.3%**） |
| Tier-2 靶标覆盖 | 55,336 | ~19,790 |
| **许可** | Non-Commercial（不可商用） | **全链 MIT/Apache** |
| 训练数据 | 单细胞型 | 三数据集联合（含 RPE1） |

## 四、两个架构选项

| 选项 | 做法 | 平台侧依赖 | 推荐 |
|---|---|---|---|
| **1. 离线导出缓存** | 写 `export_vcpe_cache.py`（对齐 AIDO 缓存 schema），在 VCPE_rna 环境批量推理一次 | **零新依赖**（只换 gz 文件+文案） | ✅ P3 首选 |
| 2. 在线推理 | 平台部署 871M 模型 + GPU + MAP 代码 | torch 全家桶 + GPU | 后续按需 |

## 五、实施顺序（待批准后执行）

1. `export_vcpe_cache.py`：加载 P2 ckpt → 对 `supported_genes` 批量推理 → 按 AIDO schema 导出 `vcpe_cache.json.gz`
2. `virtual_cell.py`：缓存路径/加载逻辑 + `is_aido`→`is_vcpe` + 文案 ×2
3. `aso_offtarget_transcriptome.py`：文案 ×1
4. `immune_sim.js`：caveat 文案
5. 用真实 ASO 查询实测：对比替换前后 Tier-2 输出，确认 schema 兼容 + 覆盖差异可见
