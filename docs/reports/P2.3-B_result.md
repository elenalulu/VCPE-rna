# VCPE-rna P2.3-B 结果报告（2026-09-02）

## 一句话结论

**条件化复活，G2'''（pearson_dev ≥ 0.30）达标**——GEARS 式逐基因残差头在 80 秒训练内做到了
SE 主干加性 pert token 三代（P2/P2.1/P2.2，合计 23 epochs）做不到的事：让扰动身份真实驱动输出。

## 架构（为什么这次成了）

```
pred_dev_i = MLP([ g_i, p, g_i⊙p, rna_p, ctrl_expr_i, is_neighbor_i, is_target_i, ds ])
```

- 每个基因的预测直接以（自身嵌入 × 扰动嵌入）为输入——扰动信息**逐基因直达**，
  不经过 600M SE 主干的残差流（P2 系的失效路径），结构上不存在"淹没"
- ESM2 表冻结 buffer（5.7M 全可训练）；STRING 邻居指示与 is_target 给出显式的
  "哪些基因该被扰动影响"先验（GEARS 同款机制）
- 协议完整继承 P2.1：残差目标 = full fc − train-only common core（防泄漏）

## P2 → P2.1 → P2.2 → P2.3-B 证据链（归档）

| 版本 | 目标 | 条件化通道 | epochs | r(real, zeroPert) | pearson_dev |
|---|---|---|---|---|---|
| P2 | 完整 fc | SE 主干 + 加性 pert token | 20 | 1.000（死） | —（被共享响应灌水） |
| P2.1 | 残差 fc | 同上 | 2 | 1.000（死） | 显示 0.92（dev 指标 bug，无效） |
| P2.2 | 残差 fc | 同上 + STRING 网络轴 | 1 | 1.000（死） | 显示 0.93（同上，无效） |
| **P2.3-B** | 残差 fc | **逐基因直出头** | 60 | **0.277** | **0.3079 ✅** |

结论：目标函数与信息源均正确，失效在**信息通路**——加性 token 进大主干残差流会被
结构性淹没；逐基因直出是数据受限场景下的正确架构。

## 诚实边界

1. **pearson_dev 0.31 是踩线达标**：1,843 扰动中可学的基因特异信号有限——当前天花板
   更可能是**数据量**而非模型；提升路径 = 更多扰动数据（LINCS L1000 perturbational 子集、
   更多 Perturb-seq 数据集），而非继续加大模型
2. ablation 置零的是 ESM2 向量，邻居/自身指示特征仍携带 pert 身份——r=0.28 为三轴合力；
   单轴贡献可后续分层消融
3. `mse_dev ≡ mse_DE`（浮点尾数差）在本协议下是数学恒等（full = common + dev 精确加回），非 bug
4. 数据集级残余共性（K562/RPE1 特异响应）可能仍被 ds one-hot 部分利用——如需隔离可加
   ds-shuffle ablation
