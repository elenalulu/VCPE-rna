## 训练曲线（lr 3e-4）

- 40 epochs 全程**零失稳**（lr 1e-3 在 ep10 塌缩进零残差盆地——数据 ×8.8 后 lr 相对过大）
- pearson_dev 单调爬升 0.136 → 0.2434（ep28 best 锁定），train_loss 0.0186 → 0.0140 持续下降
- ablation_r 全程 0.55-0.89（条件化活跃，无 shortcut 复发）

## 域梯度解读（生物学自洽）

```
replogle_ess 0.72（必需基因：敲低响应强、机制清晰）
  > hepg2 0.42 / jurkat 0.28（新细胞系，跨系泛化首次量化）
  > norman 0.51（组合扰动，pseudobulk+扩数据后大涨）
  > gwps 0.19（genome-wide：大量非必需基因敲低≈无表型，信号本质弱）
```
gwps 的 0.19 是任务本质（弱信号）+ 模型上限的混合，非 bug；它是 overall 的主要拖累（占 test 60%）。

## 口径声明（科学诚实）

1. **分布级公平对比**：旧 276-pert test 精确集合因 pseudobulk 聚合改造（items 顺序变化）不可重现；
   对比为"同源数据域分布"（LEGACY n=270），非同一集合——结论措辞为"legacy 域水位 ×2.3"而非严格同尺
2. HVG 口径：新模型用跨扰动方差选 HVG（旧为细胞间方差）——对响应预测语义更合理，但属协议变化
3. backlog：训练内 evaluate（0.2076）与 eval_fair（0.3141）同 ckpt 读数差异待排查（不影响交付）

## 工程沉淀（复用资产）

- `ingest_scperturb.py`：scPerturb → GEARS 同构（CP10K+log1p + pseudobulk 压缩，198 万细胞→1.1GB）
- `ds_knockdown.py` 流式 pseudobulk 加载：15GB 主机跑 16GB+ 数据集（峰值 5GB）
- `eval_fair.py`：分层评估工具（6 域 + legacy/new 分组 + 分块推理）
- lr 3e-4 配方：数据量 ×8.8 场景的塌缩消除
