# VCPE-rna P2 训练结果（G2' 终判报告）

- 日期：2026-09-01
- 配置：P1 cosine-best ckpt 启动 + 双轴条件化（机制轴 ESM2+KG ⊕ 序列轴 自训 RNA 编码器），
  lr 5e-5（base）/ 1e-4（rna 分支），AMP 关闭，fp32，20 epochs（1360s/epoch，3090）
- 数据/评估：与 P1 完全同协议（1,843 扰动、276 held-out、HVG-2000 + SE 嵌入空间）

## 一、终判：**G2' 达标 ✅**

| 指标 | P1 最优 | **P2 最优** | Δ | ctrl baseline | G2' 门槛 | 判定 |
|---|---|---|---|---|---|---|

**双轴假设验证成立**：RNA 序列轴的加入把 cosine 从 0.9604 平台（P1）推过 0.97 线（P2 ep12 起持续 ≥0.97，
ep18 达 0.9710），且其余指标同步改善、无此消彼长——序列信息是真实增量，不是权衡。

## 二、20 epoch 轨迹要点

- cosine 单调爬升无失稳：0.9617 → 0.9687（ep8）→ **0.9703（ep12，首次达标）** → 0.9710（ep18）
- mse 缓慢下探：0.0211 → 0.0204；P1 的两次 AMP 尖峰在 fp32 + 降 LR 下**完全消失**
- ep14-20 进入稳定平台（cosine 0.970-0.971，mse 0.0204-0.0205），边际收益收敛

交付：`ckpt_best_cosine.pt`（ep18, 0.9710）、`ckpt_best_mse.pt`（ep18, 0.0204）。

## 三、与生产基线（AIDO.RNA-Pert）的方向性对比

| AIDO.RNA-Pert（生产，17-result） | 0.984 | Non-Commercial |

## ⚠️ 勘误（2026-09-02）：G2' "达标"撤回，重新定性

diag_fc.py 三路诊断（eval-style / export-style / TRAIN 对照）+ 缓存共性核幅值核验，证据链：

| 证据 | 数值 | 含义 |
|---|---|---|
| pred_fc 幅值（diag） | std 0.113，max 1.07 | 模型输出了大幅响应（非数值塌缩） |
| 缓存共性核幅值 | HBG2 2.23 / HBG1 2.09 / EEF2 1.91 | **共性响应被完整学到**（K562 红系签名，合理） |
| **缓存残差（扣共性核后）** | **max 0.0033**（AIDO 同口径 0.419） | **基因特异判别力 ≈ 0** |
| eval-style ≈ export-style | 逐位一致 | 输入构造（S 数量/控制句来源）无罪 |
| TRAIN ≈ TEST | 无差 | **连训练时直接优化过的扰动都无残差** → 非泛化问题 |

**修正结论**：
1. P2 模型学到的是高质量的**共性响应**（K562 敲低共享转录组反应）——真实但片面
2. **条件化被架空（shortcut）**：训练损失由共性成分主导，模型学会忽略 pert token；
   四项指标（mse/pearson/cosine/top50）全部度量共享响应预测质量，G2' "达标"不成立
3. 根因：训练目标 = 完整 fc，共性核占损失大头 → 忽略条件化的代价最低
4. 修复：**P2.1 协议修正**（目标改为共性核扣除后的残差 + common head + 条件化强化 + 指标改造），
   详见 PLAN 的 P2.1 节；L2 预训练不受影响（容量扩大在协议修正后才会兑现收益）
5. cache 维持冻结，不进平台

**教训入库**：mse/pearson/cosine/top50 四项都可被共享成分灌水——扰动响应模型的评估必须
包含"去共享成分后的判别力"指标（ pearson_dev / top50_dev ），否则 G-gate 会被共性响应骗过。
