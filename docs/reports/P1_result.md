## 三、G2 判决：**条件通过，进 P2**

1. ✅ mse_DE 全面优于基线（ctrl 32% / perturbmean 93%），pearson、top50 稳定爬升
2. ⚠️ fm_cosine 0.9604，距 0.97 差 1%——**未达标但已进入平台带**（ep6-9 稳定在 0.92-0.96）
3. **P2 假设**：cosine 天花板由条件化信息量决定——当前只有"靶基因蛋白嵌入（ESM2+KG）"单轴；
   P2 接入 RNA 序列编码器（序列轴 + 机制轴双轴泛化）正是补这 1% 的设计
4. 训练不稳定（ep5/ep10 两次尖峰）为工程项：P2 跑降 LR 或关 AMP 可平滑，不改评估协议
