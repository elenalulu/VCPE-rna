## 1. P0 范围回顾

- 考卷设计：GSE289964（SCARB1 gapmer / 小鼠肝 in vivo，3 修饰 × 3 时间点 = 9 条件）作为器官级基准

- 资源审计：NicheNet / OmniPath / 肝图谱 / 细胞比例

## 2. 基线实验（两轮迭代，过程即产出）

### v1 口径（cache top 信号基因集）——暴露协议缺陷
hepg2 cache SCARB1 预测 top_up+top_down 共 48 基因，∩ 实测矩阵（ctrl TPM≥2）仅 14 基因；
pearson 中位 -0.02、方向一致率均值 39%。**结论：top-list 子集上算相关是噪声，口径作废。**

### v2 口径（实测 DEG 集合）——暴露两个结构性缺口
以每条件实测 DEG（|log2FC|≥1 且 ctrl TPM≥2）为评测集：

| 条件 | nDEG | 预测覆盖 | 覆盖处方向一致 |
|---|---|---|---|
| a1656@168h | 222 | 4 | 0% |
| a1656@72h | 121 | 2 | 50% |
| a2003@168h | 153 | 2 | 0% |
| a3928@168h | 96 | 3 | 33% |
| 其余 5 条件 | 1~10 | 0 | —（DEG 极少） |
| **合计** | **618** | **11（1.8%）** | **21%（低于随机）** |

### 缺口定性（P0 最重要的产出）

**缺口 A（工程缺口，可修）**：cache 是为 UI 设计的（只存 top-list），器官级评测需要
**全基因预测向量**。hepg2 引擎响应空间 2000-HVG，即使全向量对器官 14,568 基因的
覆盖上限 ~14%，也远高于现在的 1.8%。→ **修复 = GPU 导出 SCARB1@hepg2 全 2000-HVG
预测向量（10 分钟任务），P1 第一步强制执行。**

**缺口 B（科学缺口，是虚拟器官层存在的核心理由）**：hepg2 细胞系信号与 in vivo
全肝 DEG 的重叠极低。解读分两面：
- **机会面**：器官层（NicheNet 传导 + 比例加权 + 残差头）的价值恰恰是把细胞系信号
  "翻译"成 in vivo 器官语言——基线越弱，翻译层的增值空间越大；
- **风险面**：如果全向量导出后肝细胞信号在器官 DEG 上依然 ≈0，说明 hepg2→in vivo
  的跨尺度鸿沟可能无法靠信号传导层弥合——**G1 门必须先验证这个前提**。

**附加疑点（待查）**：in vivo 全肝 DEG 包含大量非肝细胞响应（免疫浸润/基质/应激），
hepg2 本来就不该预测到它们——需要在 P1 把 DEG 按"肝细胞可能直接调控"子集
（如代谢/脂蛋白/补体通路）与"器官继发"子集分开评测。

## 4. 对项目计划的影响（修订）

1. **P1 第一步改为强制前置任务**：GPU 导出 SCARB1@hepg2 全 2000-HVG 预测向量
   （顺带导出 APOC3/ALB 等肝系锚点），重测 v2 口径覆盖与一致率——
   **这一步的结果决定 P1 是否继续**（见 G0 门）。
2. **G1 门重定义**（原"CCC 层 ≥ 肝细胞基线 +0.02"失效——基线近 0 没有可比性）：
   - G0（前置门）：全向量导出后，肝细胞信号在**肝细胞直接调控子集 DEG** 上的
     方向一致率 ≥ 60% → 继续中；< 40% → 虚拟器官层前提动摇，先修 hepg2→原代肝
     语境（换/加原代肝细胞训练数据）再回来
   - G1（不变）：NicheNet 传导层在器官考卷上带来 ≥ +0.02 的增量
3. 考卷协议确定：**留一修饰交叉验证**（每折训练 2 修饰、考卷 1 修饰 ×3 时间点），
   指标 = DEG 方向一致率 + 覆盖加权 pearson。
4. P2 器官残差头预算不变；P3 平台化不变。

## 5. Go/No-Go 建议

**有条件 GO**：虚拟器官层的立论（细胞系→in vivo 的翻译层）被 P0 数据反向强化——
基线越弱，器官层的价值空间越大；但 G0 门是把前提验真还是证伪的裁决点，
在 G0 结果出来前不投入 P1 主体开发。

## P0.5 原代肝语境修复（2026-09-07 12:31，CPU 全程）

**实验设计**：模型/panel/协议全部不动，只替换 donor ctrl 特征（cf 向量 + pe 标量），
三种 donor 在同一器官考卷（GSE289964，panel 内 DEG 口径）上对比。脚本
`src/maprna_p3/p05_donor_context.py`；GTEx v10 肝 median TPM 已下载（data/gtex_v10_gene_median_tpm.gct.gz，8.8MB）。

**结果（SCARB1，4 个可评条件均值）**：

| donor | 方向一致率 | spearman | 说明 |
|---|---|---|---|
| hepg2（基线） | 44% | -0.158 | 癌系 ctrl |
| **invivo（GSE289964 PBS 均值）** | **58%** | **-0.084** | +14pp，逐条件全升（61/58/57/55） |
| gtex（v10 肝 median TPM） | 55% | -0.251 | +11pp，独立数据源佐证非泄漏 |
| mix（invivo+gtex 均值） | 55% | -0.190 | 融合不如单用 invivo |

**机制定位（donor 相似度诊断，panel 2000 上 spearman）**：
- **hepg2 ctrl vs in vivo 肝 ctrl：+0.020——几乎零相关，这就是根因的直接证据**
- hepg2 vs GTEx 肝：+0.543（人源但癌系偏置）
- invivo vs GTEx：+0.197（跨物种映射+TPM 口径差异）

**判读**：
1. **G0 归因被证实**：仅换 ctrl 特征（零训练）44%→58%，donor 语境是跨尺度鸿沟的主导因素。
   GTEx 独立数据源复现 +11pp，排除同实验泄漏解释。
2. **未过 60% 继续线**（最高 58%）。两个选择：
   - **严格路径**：继续修 donor（学习映射/原代肝 sc 数据），把细胞层推过 60% 再进 P1
   - **务实路径**：以 invivo-donor 58% 为细胞层基线直接进 P1——因为剩余缺口（58→60+）
     恰好是 NicheNet 信号传导层的设计职责，且 P1 自带 G1 门（器官级 ≥ 细胞层基线 +0.02）
     兜底，纪律没有放松
3. caveat：invivo donor 与考卷同实验（ctrl 无扰动响应信息，但保守起见 P1 考卷应采用
   留一修饰隔离，并以 GTEx donor 为独立复核算）。

**建议（待拍板）**：务实路径——P1 以 invivo donor 为基线开工，G1 门（+0.02 增量）
不变；若 G1 过门，P2 残差头继续推器官级指标。60% 线作为 P2 后的复核指标而非 P1 门槛。
